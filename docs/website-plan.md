# Website Plan

## Primary user questions

The site should answer these within about 30 seconds:

1. What is this community?
2. Who is it for?
3. What happens here?
4. When is the next event?
5. How can I participate?

## Navigation

- Home
- About
- Café
- Forum
- Resources
- Join
- EN

## Content model

### Café
Small, recurring, discussion-centered sessions.

### Forum
Structured events with invited speakers or specialists.

### Resources
Public outputs from the community: reports, workflows, checklists, surveys, and references.

## Editing principle

Keep reusable facts in `src/data/` and keep pages focused on presentation. This makes renaming the organization or updating events easy for both humans and coding agents.
